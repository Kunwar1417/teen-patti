# Teen Patti Hisaab

A pot tracker and scorekeeper for Teen Patti nights with friends. It does not run any game and never handles money; it just keeps the table's maths straight.

- Collect the boot from every player in one tap, then tap a player's colored slice to add the current bet
- Set your own starting boot and an optional pot limit (tap the current bet)
- Optional Blind mode: seen players automatically pay double
- Pack players, split the pot between multiple winners, undo anything
- Table, Scores and History tabs; reopen the last round to fix a mistake
- End Game & Settle Up: who pays whom, share to WhatsApp
- English and Hindi (हिंदी); drag players into your seating order
- Works offline; scores are saved only on your device
