# Teen Patti Hisaab

A pot tracker and scorekeeper for Teen Patti nights with friends. It does not run any game and never handles money; it just keeps the table's maths straight.

- Collect the boot from every player in one tap, then tap a colored slice to add the current bet for a player
- Set your own starting boot and an optional pot limit (tap the current bet)
- Pack players, split the pot between multiple winners
- Live round dashboard, overall scoreboard, round history
- End Game & Settle Up: who pays whom, share to WhatsApp
- Scores are saved on each device
